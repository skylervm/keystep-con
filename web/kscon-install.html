KeyStep Con · Install KSCON firmware

Open the KeyStep Con editor

Experimental Chroma and Ableton tempo fork of KeyStep Con. This build has offline emulator coverage. Physical-device validation is pending.

This page makes the KSCON file from your own copy of Arturia's update, here in your browser (nothing is uploaded), and walks you through flashing it. To go back, flash Arturia's file the same way.

What it adds

  • Make bass: a bass line that follows the chords of another track, in five styles.
  • Drum pads: play the drum lanes from the 16 steps while the keys play another track.
  • Chord pads: chords from the track's scale on the steps, or chords you keep there.
  • Root chords: a key sets the root, the steps play 16 chord types.
  • Key lights and recording for every pad note, drum hits included.
  • Project names and a KEYSTEP CON startup screen.

Full details: the README.

What you need

  • A standard or Chroma KeyStep Pro, its official power adapter and USB cable. This fork patches both model images; neither has physical validation of this build yet.
  • A Mac or Windows computer with MIDI Control Center (Arturia's free app), which does the flashing.
  • Arturia's 2.5.20 update file, keystep-pro_Firmware_Update_2.5.20.0.kspf. MIDI Control Center installs it; on a Mac it is in /Library/Arturia/MIDI Control Center/.
  • This page works in any current browser. Backing up needs Chrome or Edge.
1

Back up your projects

Projects have come through every KSCON flash so far, but back them up anyway. Open the editor's backup tool, connect the KeyStep and save all 16 projects to a file (about 10 minutes). MIDI Control Center can also back up projects.

Open the backup tool
2

Make the KSCON file

Choose Arturia's 2.5.20 update file. The page checks that it is exactly the official 2.5.20, adds KSCON's changes and checks the result against the tested build before offering it.

3

Flash it with MIDI Control Center

Close any page that is connected to the KeyStep (like the editor), so MIDI Control Center has it to itself. Open MIDI Control Center with the KeyStep Pro connected, use its firmware update and pick the file you just downloaded, KSCON_….kspf, instead of Arturia's. Leave the KeyStep connected until it restarts.

4

Check it worked

The startup screen says KEYSTEP CON. Shift + Project > Utility > FW version shows KSCON 2.5.99, and MIDI Control Center reports version 2.5.99. Load a project to check your projects are all there; restore from the backup if anything is missing.

Going back to Arturia's firmware

Flash keystep-pro_Firmware_Update_2.5.20.0.kspf with MIDI Control Center the same way. KSCON reports 2.5.99, so MIDI Control Center may treat this as a downgrade; that is expected.

Validation and limits

This experimental fork passes offline firmware and Live-bridge tests. Hardware timing, the real display, sequencing and settings preservation still need device tests. Back up projects and device settings, keep the official stock package for rollback, and review the exact candidate before flashing. The page checks the supported stock inputs and its output against the locally built package.

Why do I need Arturia's file?

The firmware is Arturia's, so KSCON does not redistribute it. This page carries only the few kilobytes KSCON changes and applies them to your copy.
